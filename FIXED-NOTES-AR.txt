ALMASRI ENGINEERING - MONGODB SAFE BUILD 2.3.0

- الواجهة ووظائف الموقع بقيت كما هي.
- MongoDB هي قاعدة البيانات الوحيدة.
- أزيل تخزين SQLite/JSON من هذه النسخة.
- تم تحسين إعادة استخدام الاتصال، الفحص عند التشغيل، الفهارس، ورسائل أخطاء MongoDB.
- تمت إزالة بيانات اتصال MongoDB القديمة من المشروع.
- ملف .dev.vars يحتوي مكانًا فارغًا للرابط الجديد فقط.
- استخدم npm run db:check قبل npm run dev.
